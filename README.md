> Aprendemos Ingeniería de Software haciendo Ingeniería de Software.

Repositorio académico público y reutilizable para el aprendizaje basado en proyectos. Se inspira en la experiencia práctica de CS50, pero se organiza por **temas**, no por semanas.

## Empieza aquí

1. Consulta el [programa](programa/README.md) y la [guía estudiantil](docs/guia-estudiantil.md).
2. Selecciona un [tema](temas/README.md): objetivos, recursos y enlaces a prácticas.
3. Realiza [actividades](actividades/README.md): codelabs guiados, notebooks experimentales y challenges autónomos.
4. Aplica lo aprendido al [proyecto integrador](proyecto-integrador/README.md) del período académico.

## Cómo trabajamos

**Comprender → Experimentar → Construir → Demostrar → Aplicar.** Cada tema enlaza solamente las actividades pertinentes; no se exige que todos tengan notebook, codelab y challenge. Los trabajos de equipos se desarrollan en [YaskCode-laboratory](https://github.com/YaskCode-laboratory).

## Evaluación y privacidad

Los criterios y ponderaciones oficiales se publicarán tras su validación docente. Las actividades públicas no contienen matrículas, calificaciones, datos personales ni claves. La integración con Classroom 50 o PrairieLearn está **en evaluación**, no implementada.
