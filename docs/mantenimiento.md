# Mantenimiento y futura integración Classroom

## Separación de responsabilidades

- `temas/`: ruta de aprendizaje y enlaces.
- `actividades/`: fuente única de ejercicios, validadores y metadatos.
- `proyecto-integrador/periodos/`: proyectos cambiantes sin alterar la estructura general.

## Contrato de actividad sugerido

Identificador estable, tema, tipo, ruta, versión, criterios de evaluación, referencia de pruebas y modalidad. El Classroom deberá mapear **estudiante (privado) + período + actividad + resultados**, independientemente de las rutas físicas.

No activar inscripción ni registro público de estudiantes antes de aprobar privacidad, autenticación, retención y control de acceso. No guardar notas individuales en GitHub público.
