# YaskCode Codelabs

Guías por pasos con objetivos y verificaciones ejecutables en un entorno real. La interfaz puede indicar qué comprobaciones pasaron; el registro por estudiante requiere identificación y almacenamiento privados, por lo que no debe presentarse como función ya disponible.

Cada codelab tendrá README, guía, aplicación de ejemplo (si procede), comprobaciones y metadatos de actividad.
