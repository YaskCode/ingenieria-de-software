# Actividades prácticas

Esta carpeta centraliza las actividades reutilizables y su mantenimiento técnico:

- [Codelabs](codelabs/README.md): aprendizaje guiado por pasos y comprobaciones reales.
- [Notebooks](notebooks/README.md): exploración y experimentación con código.
- [Challenges](challenges/README.md): resolución autónoma y evaluación mediante evidencias.

Cada actividad debe tener un **identificador estable**, instrucciones, requisitos previos, tema(s), pruebas y criterios de finalización. Los temas enlazan aquí. La integración con Classroom 50 / PrairieLearn **no está implementada**.

Ejemplo de identificador: `IS-T04-CL01`. No incluyas nombres ni datos de estudiantes en repositorios públicos.
